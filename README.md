## О проекте

**Народный VPN** — десктопный VPN-клиент для Windows, который позволяет направлять трафик конкретных приложений через VPN-туннель, не затрагивая остальной системный трафик. Поддерживает два режима маршрутизации, 28 популярных сервисов, несколько прокси-протоколов и автоматическое переподключение — всё это в интерфейсе с тёмной и светлой темой.

Этот репозиторий — десктопный клиент, часть более крупного VPN-сервиса. Клиент полностью управляет VPN-процессами локально: запускает прокси-движок, настраивает сетевые маршруты Windows, проверяет права администратора и отображает актуальный статус подключения.

## Возможности

### Режимы маршрутизации
| Режим | Описание |
|-------|----------|
| **Proxy mode** | Маршрутизирует выбранные приложения через SOCKS5/HTTP-прокси; настраивает системный прокси Windows |
| **TUN mode** | Создаёт виртуальный сетевой адаптер через Tun2Socks; маршрутизирует трафик на уровне ОС |

### Раздельная маршрутизация (Split Tunnel)
Выбери конкретные приложения, трафик которых пойдёт через VPN:

| Категория | Сервисы |
|-----------|---------|
| Соцсети | Discord, Telegram, Twitter, Instagram, Facebook, TikTok, Reddit, Snapchat, LinkedIn |
| Видео | YouTube, Netflix, Twitch |
| Игры | Roblox, Steam, Brawl Stars |
| AI / Разработка | ChatGPT, Claude, Gemini, Grok, GitHub |
| Дизайн | Canva, Figma, Notion |
| Музыка | Spotify, SoundCloud |

Для каждого сервиса прописаны домены и IP CIDR-диапазоны вручную (например, 40+ CDN-эндпоинтов Discord + 18 регионов голосовых серверов).

### Другие возможности
- Мульти-протокол: **VLESS + Reality/TLS** и **Shadowsocks**
- **Автоподключение** — 5 попыток с интервалом 5 секунд при обрыве
- **Определение IP / страны / города** с отображением флага
- **Измерение задержки серверов** (TCP-пинг до каждого сервера)
- **Режим маскировки** — автовыбор сервера для обфускации трафика
- **Обход DPI для Roblox** через Zapret / WinDivert
- Проверка прав администратора (необходимо для TUN-режима)
- Тёмная / светлая тема, сохраняется в localStorage
- Автозапуск при входе в Windows

## Стек технологий

### Фронтенд
- **React 18** + **TypeScript 5** — UI
- **Tailwind CSS 4** — стили
- **Lucide React** — иконки
- **Vite 5** — сборка и dev-сервер

### Бэкенд (Electron Main Process)
- **Electron 30** — оболочка, IPC, управление процессами
- **Node.js `child_process`** — запуск VPN-бинарников
- **PowerShell** — инъекция маршрутов, проверка прав, настройка системного прокси

### VPN-движок (бинарники в комплекте)
| Файл | Роль |
|------|------|
| `xray.exe` | Ядро прокси (VLESS, Shadowsocks) |
| `tun2socks.exe` | TUN-адаптер |
| `winws.exe` + `WinDivert` | Перехват пакетов, обход DPI |
| `wintun.dll` | Виртуальный TUN-драйвер |
| `geoip.dat` / `geosite.dat` | Базы GeoIP для маршрутизации Xray |

### Сборка и дистрибуция
- **Electron Builder** → NSIS-инсталлятор (64-bit Windows `.exe`)
- **JavaScript Obfuscator** — RC4 + ротация строковых массивов

## Архитектура

```
┌────────────────────────────────────────────────┐
│              React UI  (Renderer)              │
│  App.tsx · Модалки · Тема · Toast-уведомления  │
└──────────────────┬─────────────────────────────┘
                   │  IPC (contextBridge)
┌──────────────────▼─────────────────────────────┐
│           Electron Main Process                │
│  main.ts · Валидация ключа · Управление конфиг │
│  Запуск процессов · Инъекция маршрутов (PS)    │
└──────┬──────────────────────────┬──────────────┘
       │                          │
┌──────▼──────┐           ┌───────▼───────┐
│  xray.exe   │           │ tun2socks.exe │
│  SOCKS/HTTP │           │  TUN-адаптер  │
│  прокси     │           │  (TUN-режим)  │
└─────────────┘           └───────────────┘
```

**Процесс подключения:**
1. Пользователь вводит API-ключ → проверка на сервере
2. Список серверов загружается как base64-подписка (VLESS/SS-ссылки)
3. Пользователь выбирает сервер и приложения для маршрутизации
4. `vpnConfig.ts` генерирует JSON-конфиг для Xray с правилами маршрутизации
5. Xray стартует как локальный прокси (SOCKS5 `:10808`, HTTP `:10809`)
6. В TUN-режиме — Tun2Socks связывает TUN-адаптер с SOCKS-прокси Xray
7. PowerShell прописывает маршруты ОС для IP-диапазонов выбранных приложений
8. При отключении — маршруты удаляются, процессы завершаются, прокси сбрасывается

## Разработка

### Требования
- Node.js 20+
- Windows (используются Windows-специфичные API и бинарники)
- Права администратора (для TUN-режима при разработке)

### Запуск в режиме разработки

```bash
npm install
npm run dev        # Dev-сервер с горячей перезагрузкой (Electron + Vite)
```

### Сборка и пакетирование

```bash
npm run build      # Компиляция TypeScript + сборка Vite
npm run obfuscate  # Обфускация исходников Electron
npm run dist       # Полная production-сборка → NSIS-инсталлятор в release/
```
